🔒 How to Add a GitHub Repository Secret
⚠️ SECURITY WARNING: Never store API keys, tokens, or secrets in settings.txt! Everything in settings.txt is committed to your public GitHub repository.
  1. Open your profile repository on github.com.
  2. Click on Settings (top navigation tab of the repository).
  3. In the left sidebar under Security, click Secrets and variables → Actions.
  4. Click the green New repository secret button.
  5. Enter the exact Name (e.g. STEAM_API_KEY, MARKET_API_KEY, TWITCH_CLIENT_ID, or TWITCH_CLIENT_SECRET) and paste your secret key into Secret.
  6. Click Add secret. The daily GitHub Action workflow will automatically read it via ${{ secrets.NAME }}.
